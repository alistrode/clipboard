# 1.0.3 预览边界与滚动

卡片改为 76px 后，旧三行预览的高度超过内部空间。现预览固定为两行、每行 24px；限制最小宽度与最大高度，允许无空格长字符串在可用空间内断行。管理表格保留单行省略。数据库完整文本不受预览限制。

虚拟列表加载期间，用户继续滚动时保留最新滚动位置；当前分页未覆盖视口则继续加载。尚未加载的条目不会错误保存成旧锚点，重新显示时可使用已保存锚点。

本地 Linux Xorg 打包版：320 条混合中文、长字符串、多行文本，弹出窗口和管理窗口均通过预览边界、快速跨页滚动、隐藏重新显示、浏览期间新增记录保持锚点检查。关闭进程再启动，弹窗恢复到同一条记录及 56px 条目内偏移。真实 XTest 鼠标滚轮使 scrollTop 从 9884 增加到 11324，可见区域仍有已加载条目。
